Первая версия. в планах запилить:

Сделать раздел запуска батников 
В нем скан папки элемент, батники по маске ищутся 
Фича запуска ручного пачками (Пкм трей - пачка 1, пачка 2 и тд), в настройках количество окон на пачку и задержка между запусками в секундах. Расчет оптимального времени задержки по кнопке отталкиваясь от параметров ПК и быстродействия Windows.
Фича автозапуска пачек по очереди после закрытия всех окон элементклиента
Фича исключения ненужных батников из запуска по кнопке минус, список исключений с кнопкой плюс что бы вернуть батник в пачки, автоисключение при первом сканировании стандартных батников пустых от комбека
Ручное добавление и удаление батников по одному из списка и в список запуска

Даркмод подтягивается из настроек система и по выбору ещё

Вкл\выкл трей иконку. При выключении всплывашка что в конфиге поменяйте параметр скрытия на 0 для отображения трей иконки, или удалите конфиг файл
